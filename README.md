# 🧮 Matteeksamen 2026 — Komplett Lærings-hub

Interaktiv nettside bygget for å hjelpe elever på 10. trinn med å forberede seg til matteeksamen 26. mai 2026. Kombinerer videoinnhold, adaptiv øving, studieplan og eksamenssett i én samlet hub.

## 🔗 Åpne siden

[kjerstiaga.github.io/ane-matte](https://kjerstiaga.github.io/ane-matte)

## 📚 Innhold

| Fane | Beskrivelse |
|------|-------------|
| 📻 NotebookLM | Videopresentasjon + kopierbart script til AI-podkast |
| 📅 Studieplan | 12-dagers plan med avkryssing (lagres i nettleseren) |
| 📐 Teori | Innebygd slideshow (9 slides) + hurtigteori-kort |
| 📈 Lineære funksjoner | 8 adaptive oppgaver — y = ax + b |
| 🚀 Eksponentialfunksjoner | 8 adaptive oppgaver — y = a·bˣ |

| 🏆 Eksamenssett | Del 1 (uten hjelpemidler) + Del 2 (med hjelpemidler) |

---

## ⚡ Funksjoner

- **Adaptiv vanskelighetsgrad** — oppgavene justeres automatisk etter svarene dine
- **XP og streak** — motivasjonssystem som holder deg i gang
- **Innebygd slideshow** — The Math Blueprint presentasjon (alle 9 slides)
- **Video** — 12-dagers plan og 3C-metoden
- **Studieplan med avkryssing** — lagres lokalt i nettleseren
- **Eksamenssett** — realistiske oppgaver i samme format som virkelig eksamen
